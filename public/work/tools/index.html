不動産の仕事で、実際に使っている道具

作っただけで終わった道具ではありません。不動産の仕事で、いまも自分で使っているものを置いています。

何でも一つで済ませるためではなく、いま止まっている一つの作業を進めるために。先に記事の手順を読み、必要な道具だけ選んでください。

Windowsで使うDAKE

こんなとき：契約資料・物件資料が複数のPDFに分かれている。

DakePDF結合

PDFを画面上で並べ替え、表示順に一つのPDFへ結合します。

元資料は保管し、送付用を別に作ります。電子署名や添付情報の維持を前提に加工しないでください。

利用環境・保存・できないこと

Windows / 公開版 v1.0.1

端末内でPDFを処理し、結合したPDFを保存します。設定ファイルを使用します。

契約内容の照合や、必要書類が揃っているかの判断はしません。

こんなとき：長いPDFから、必要なページだけ取り出したい。

DakePDF分割Select

サムネイルやページ範囲で選び、必要なページを新しいPDFへ保存します。

抜粋を全文の代わりに保管しないでください。配布版はexeだけでなくフォルダ一式で使います。

利用環境・保存・できないこと

Windows / 公開版 v1.0.1

端末内で処理。保存先を選ばない場合は元PDFと同じフォルダへ出力し、同名は連番にします。

抜粋してよい範囲や、相手への説明が足りるかは判断しません。

DakePDF分割Selectの詳細を見る

不動産実務での手順を読む

こんなとき：一つのPDFを、全ページ一枚ずつのファイルに分けたい。

DakePDF分割One

PDF一件を追加すると、全ページを個別のPDFへ自動分割します。

投入すると処理が始まります。必要なページだけ選ぶときはSelectを使います。

利用環境・保存・できないこと

Windows / 公開版 v1.0.1

端末内で処理。GUIの初期保存先はDownloads。保存先設定を保持し、新しい出力フォルダを作ります。

書類のまとまりや、ページごとの資料名を自動判定しません。

DakePDF分割Oneの詳細を見る

不動産実務での手順を読む

こんなとき：契約書やスキャン資料が重く、添付しづらい。

DakePDF圧縮

PDFに合う圧縮方法を自動で選び、元PDFを上書きせず別名保存します。圧縮後のサイズと削減率を確認できます。

PDFによって圧縮効果は異なります。十分に軽いPDFは保存しない場合があります。送る前に文字・図面の読みやすさを確認します。

利用環境・保存・できないこと

Windows / 公開版 v1.1.0

端末内で処理し、元PDFと同じフォルダへ別名保存します。同名がある場合は連番を付けます。元PDFを保管して比較してください。

必ず指定容量以下にすることや、画質・電子署名等の維持は保証しません。暗号化・破損PDFを処理できない場合があります。

DakePDF圧縮の詳細を見る

こんなとき：scan001.pdfが並び、開くまで中身が分からない。

DakePDF俯瞰名前変更

フォルダ直下のPDFを一ページ目のサムネイルで俯瞰し、入力した名前をまとめて反映します。

元ファイルの名前が変わります。先にバックアップを取り、反映前の一覧を確認します。

利用環境・保存・できないこと

Windows / 公開版 v1.0.2

ネットワーク通信なし。PDF本文は変えず、端末内のファイル名を変更します。直前の一括変更を一回Undoできます。

OCR、AI自動命名、本文編集、サブフォルダの再帰処理はしません。

DakePDF俯瞰名前変更の詳細を見る

こんなとき：管理会社へ提出するリフォーム工事工程表を作りたい。

マンション工程表

日程と工事項目を整理して、A3横一枚の工程表PDFを作ります。

管理会社指定様式と施工会社の日程を先に確認します。初期工程をそのまま施工の約束にしないでください。

利用環境・保存・できないこと

Windows / 公開版 v1.0.1

PDFを端末へ保存。会社支店名・担当者名・連絡先を次回起動用に端末内へ保持します。

工事申請、管理規約の判断、工事許可の取得や進捗管理は代行しません。

マンション工程表の詳細を見る

ブラウザで使う道具

こんなとき：物件写真や資料一式をメール添付で送れない。

DakeSend

ファイルやフォルダをアップロードし、七日間限定のURLで渡します。

送信には招待またはGuest Passが必要です。受信者の登録は不要。社内の外部共有ルールを確認してください。

利用環境・保存・できないこと

Webブラウザ

ファイルと転送情報をサービスのサーバーに保存します。保管期限は七日間で、永続保管用ではありません。

受信後の再共有防止やウイルス検査、安全性の一律保証はしません。

DakeSendの詳細を見る

不動産実務での手順を読む

こんなとき：契約日から決済・引渡し日まで、何日あるか確認したい。

日数計算

開始日と終了日の間の日数と、暦上の期間を確認します。

日数の数え方を確認して使います。法律・契約上の期限を確定する道具ではありません。

利用環境・保存・できないこと

Webブラウザ

日付と結果はブラウザ内で計算し、保存・送信しません。

契約条項の解釈や、個別の法定期限の判断はしません。

日数計算の詳細を見る

不動産実務での手順を読む

こんなとき：和暦・西暦の建築時期から、現在の築年数を確認したい。

築年数・耐震基準 早見

築年数、西暦・和暦、建築基準の主な節目を参考として確認します。

建築年月や基準日を元資料と照合します。築年数だけで建物の安全性や価値は決まりません。

利用環境・保存・できないこと

Webブラウザ

建築時期・基準日・構造・建築確認日・結果を保存せず、ブラウザ内で計算します。

耐震性、安全性、法適合、融資可否、建物価値を判定しません。

築年数・耐震基準 早見の詳細を見る

不動産実務での手順を読む

こんなとき：メールや物件登録で、入力と修正に細かな時間が掛かる。

DAKE Typing

仕事に近い用意された教材で、文字入力や基本操作を練習します。

実案件や顧客情報は入力しません。結果は本人の練習の目安として扱います。

利用環境・保存・できないこと

Webブラウザ（PCキーボードでの練習を中心に）

入力本文やキー履歴は解析へ送りません。進捗は端末内に保持します。詳しくは公開サイトのプライバシー案内へ。

実務の習熟度や担当者の能力を総合評価する道具ではありません。

DAKE Typingの詳細を見る

不動産実務での手順を読む

こんなとき：月末で画面が切れて、契約から決済までを見渡せない。

スクロールカレンダー

月境界で切らず週の流れを連続表示し、期間選択やA4 PDF印刷ができます。

選択期間は両端を含めて数えます。確定日・候補日・未確認の日を手元の工程表で分けてください。

利用環境・保存・できないこと

Webブラウザ

日付・選択期間・結果・印刷本文を保存・送信せず、ブラウザ内で扱います。

関係者への予約、通知、契約期限の判断はしません。

使う前に

公開仕様の確認日：2026年9月30日。配布条件や最新の対応環境は各公式ページでご確認ください。Web版に公開version番号がない場合は番号を付けていません。ブラウザの個別versionへの対応は各サイトの案内によります。

PDFの元資料は保管し、加工した資料は送付用として扱います。DakeSendはファイルをサーバーに預けるサービスです。ブラウザ内で計算する日付等の道具とは保存方針が異なります。

執筆・確認：菊田幸彦

解析設定・プライバシー

初期状態ではアクセス解析を行いません。許可した場合だけ、Google Analyticsでページ表示、記事の共有、プロフィールや道具へのリンク、戸建買取査定の案内、メールアドレスの表示・コピーが使われたかを計測します。

入力した住所や個人情報、メールアドレス、認証情報、コピーした内容、資料やファイルの情報、記事本文・タイトルは計測に含めません。ページは決められた識別情報で扱い、URLの検索条件や末尾の付加情報を送りません。

選択はこのブラウザに保存され、解析設定から変更できます。ブラウザがGPCで拒否を伝えている場合も解析しません。拒否しても閲覧とメール表示・コピーを利用できます。表示時のCloudflare Turnstileは自動アクセスを防ぐための確認で、アクセス解析とは別です。
