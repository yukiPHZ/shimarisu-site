物件フォルダがscan001.pdfだらけ。資料名を整理するには

査定資料のフォルダにscan001.pdfからscan020.pdfまで並んでいる。公図を探すために何度も開き直す。担当が替わると、どこまで確認したかも伝わりません。

先に名前の型を一つ決めます。「資料種別・対象・資料の日付」の順にし、分からない資料を想像で命名しません。

先に整理すること

  • 登記、公図、地積測量図、建築確認、評価証明、管理資料をまず大まかに分ける。
  • 資料の発行日・取得日・スキャン日を混ぜない。どの日付を使ったか分かる名前にする。
  • 「最新版」「確定」などの語は、確認できた場合にだけ付ける。

手元の道具でも進められる手順

  1. フォルダ全体をバックアップします。名前を使って参照する社内台帳があれば、変更してよい範囲も確認します。
  2. 一件ずつ開き、書類の表題、対象、日付を確認します。
  3. 架空の例なら「01_登記_建物_取得20260901.pdf」「02_公図_取得20260901.pdf」のように揃えます。実際の顧客名や住所を公開サンプルにしません。
  4. 不明なものは「要確認_資料01」のように残し、判断したものだけ名前を変えます。

DakePDF俯瞰名前変更を使う場合

  1. DakePDF俯瞰名前変更で対象フォルダを選びます。直下のPDFの一ページ目を見渡せます。
  2. カードへ新しい名前を入力し、反映前の確認画面で変更対象と新旧名を照合します。
  3. 変更分だけ反映します。直前の一括変更のUndoはできますが、バックアップの代わりにはしません。

DakePDF俯瞰名前変更の詳細を見る

Windows。ネットワーク通信なし。PDF本文は変えず、端末内のファイル名を変更します。直前の一括変更を一回Undoできます。

使った後に確認すること

  • 改名後のファイルを開き、内容と名前が一致しているかを確認する。
  • 建物と土地、複数棟、旧年度と新年度を取り違えていないか見る。
  • 管理資料など複数ページのPDFは、表紙だけで種類を決めず本文も見る。

注意しておきたいこと

サムネイルは名前を考える手掛かりです。OCRやAIによる自動命名はしません。PDF本文は変えませんが、元ファイルの名前は変わります。共有リンクや台帳の参照へ影響しないか確認してください。
